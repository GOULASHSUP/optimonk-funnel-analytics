# Funnel Analytics Mini App

A small Vue mini-app for analyzing step-level funnel performance in popup campaigns.
The app helps marketers understand where users drop off inside multi-step popup flows instead of only seeing the final overall conversion rate.

## Features

- Campaign list with basic performance metrics
- Step-by-step funnel view for the selected campaign
- Conversion and drop-off calculations for each step
- Highlighted biggest drop-off step
- Simple rule-based insights and recommendations

## Tech stack

- Vue 3
- Vite
- Tailwind CSS
- Static JSON data

## How to run the project

### Prerequisites

- Node.js 20 or newer
- npm

### Installation

```bash
npm install
```

### Start development server

```bash
npm run dev
```

Open the local URL shown in the terminal, usually:

```txt
http://localhost:5173/
```

### Build for production

```bash
npm run build
```

## Notes

The app uses static JSON data because the assignment does not require authentication, a real database, or a production backend.

The recommendations are rule-based instead of generated by a live AI model to keep the v1 simple, transparent, and easy to review.
